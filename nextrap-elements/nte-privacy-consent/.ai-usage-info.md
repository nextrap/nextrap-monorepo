# AI usage information: @nextrap/nte-privacy-consent

Use `<nte-privacy-consent>` for one site-wide, HTML-first privacy prompt. It groups inert `script[type="text/plain"][data-consent-service]` and `template[data-consent-service]` declarations, stores the versioned choice and activates accepted resources.

```html
<nte-privacy-consent policy-version="2026-08" show-reject-all>
  <script type="text/plain" data-consent-service="analytics" data-consent-label="Analytics" data-src="/analytics.js"></script>
  <template data-consent-service="youtube" data-consent-label="YouTube"><iframe src="..."></iframe></template>
</nte-privacy-consent>
```

Use `nte-consent-blocker` instead for a local placeholder around one embed. Increment `policy-version` after material service/policy changes. Do not place required scripts inside this element. Script side effects cannot be undone generically after withdrawal.
