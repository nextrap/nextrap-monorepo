# @nextrap/nte-element-highlighter

## Entry Points

- SPA: `import '@nextrap/nte-element-highlighter'` lädt API und Default-Light-DOM-Styles automatisch.
- Theme/Seaming: `import '@nextrap/nte-element-highlighter/unstyled'` enthält keine direkten oder transitiven Light-DOM-Styles; Sass-Mixins explizit im Theme einbinden.
