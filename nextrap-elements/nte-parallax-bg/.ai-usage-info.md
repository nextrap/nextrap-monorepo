# @nextrap/nte-parallax-bg

Parallax/background image web component.

## Import

```ts
import '@nextrap/nte-parallax-bg';
```

## Usage

```html
<nte-parallax-bg image="/hero.jpg"></nte-parallax-bg>
```

Use it as a decorative background element, for example in the `bg` slot of `ntl-hero`.

## Styling

Theme styling should target exposed parts and Light DOM selectors. Keep the Shadow DOM CSS functional and minimal.
