# @nextrap/nte-consent-blocker

Consent-gate element component for embedding external content only after user approval.

## Import

```ts
import '@nextrap/nte-consent-blocker';
```

For styling:

```scss
@use '@nextrap/nte-consent-blocker' as consentBlocker;
```

## Usage

```html
<nte-consent-blocker class="default">
  <template>
    <iframe title="Map" src="..."></iframe>
  </template>
</nte-consent-blocker>
```

- Direct `.background` children or direct `p:has(img:not(.keep))` children are assigned to the `background` slot.
- Direct `<template>` content is cloned into `consented-content` after a click on `[data-action="consent"]`.
- If no direct template exists, `--default-template-selector` can reference a reusable document template, for example `#map-template`; its content is copied into a new direct template during initialization.
- Missing background and pre-consent slots show the built-in Maps preview and consent prompt as Shadow-DOM slot fallbacks.
- `--default-background-selector` and `--default-pre-consent-selector` optionally assign copied content from reusable document templates, replacing those fallbacks.
- Direct templates and slot content take precedence over selector defaults, so the normal short usage requires only the consented-content template.

## Ausnahme von der Regel

Der `nte-consent-blocker` darf auch in Markdown-Dateien als HTML eingebunden werden. Optimalerweise wird `pre-consent`
per CSS gesetzt. Dies betrifft nur das Element `<nte-consent-blocker>` selbst.

## Parts

Use `::part(wrapper)`, `::part(background)`, `::part(pre-consent)`, `::part(consented-content)` and `::part(loading-text)` for theme styling.

## Mixins

```scss
@include consentBlocker.default-style();
@include consentBlocker.pairing-ntl-2col-in-nte-consent-blocker($top-aspect-ratio: 21 / 9);
```

`default-style()` accepts optional `$default-background-selector` and `$default-pre-consent-selector` values for global theme configuration. Keep Shadow DOM styles functional only; visual styles belong in package SCSS mixins.

## Pairing

See `demo/pairing-ntl-2col.md` for examples where `nte-consent-blocker` is placed in `ntl-2col` as `.aside` and `.top` content.
