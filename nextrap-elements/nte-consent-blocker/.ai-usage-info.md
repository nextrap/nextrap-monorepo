# @nextrap/nte-consent-blocker

Sperrt externen Template-Inhalt bis zur Freigabe über einen Button mit `data-action="consent"`.

## Verwendung

```ts
// Registriert die Komponente ohne Light-DOM-Styles.
import '@nextrap/nte-consent-blocker';
```

Das Theme stellt ein dokumentweites, inertes `template#map-template` mit dem Embed bereit:

```md
---
{: layout="nte-consent-blocker" section-style="--default-template-selector: #map-template;"}
```

- Ein direktes `<template>` hat Vorrang; dessen Inhalt wird erst nach Freigabe nach `consented-content` kopiert.
- Fehlende `background`- und `pre-consent`-Slots erhalten Maps-Vorschau und Hinweis als Light-DOM-Inhalte.
- `--default-background-selector` und `--default-pre-consent-selector` wählen stattdessen globale Templates.
- Direkte Slot-Inhalte haben Vorrang; direkte `.background`-Kinder und `p:has(img:not(.keep))` werden automatisch zugeordnet.
- Selector-Defaults werden bei der Initialisierung gelesen; gemeinsame Templates müssen dann bereits existieren.
- Das eingebaute Vorschaubild kommt vor der Freigabe von `cdn.leuffen.de`; gesperrt ist der Embed-Inhalt.

## Styling

```scss
// Das Theme stellt Tokens bereit und bindet die öffentliche Baseline ein.
@use '@nextrap/style-base/default';
@use '@nextrap/nte-consent-blocker' as consentBlocker;

// Die Style-Klasse wird automatisch ergänzt; das Pairing ist bei Verwendung in ntl-2col optional.
nte-consent-blocker.style-default {
  @include consentBlocker.default-style();
  @include consentBlocker.pairing-ntl-2col-in-nte-consent-blocker();
}
```

- `index.scss` ist ausgabefrei; `default.scss` materialisiert nur `nte-consent-blocker.style-default`.
- Genau eine `style-*` Klasse pro Instanz; eigene Varianten benötigen eine vollständige Baseline.
- Parts: `wrapper`, `background`, `pre-consent`, `consented-content`, `loading-text`.
- `--aspect-ratio`: 16:9, mobil 1:1; `--breakpoint`: `lg`. Instanzwerte über `section-style`.
- Visuelle Variablen: `--border-radius`, `--overlay-background`, `--pre-consent-padding`.
- `default-style()` behält die optionalen Selector-, Radius-, Overlay- und Padding-Parameter bei.
- Das Theme gestaltet die Light-DOM-Buttons mit `@nextrap/style-button`; der Shadow DOM enthält nur funktionale Regeln.
- Pairing: direkte `.aside`- und `.top`-Blocker in `ntl-2col`; Top ist standardmäßig 21:9 in allen Modi,
  konfigurierbar über `$top-aspect-ratio`.
