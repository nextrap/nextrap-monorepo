# @nextrap/nte-theme-switcher

## Entry Points

- SPA: `import '@nextrap/nte-theme-switcher'` lädt API und Default-Light-DOM-Styles automatisch.
- Theme/Seaming: `import '@nextrap/nte-theme-switcher/unstyled'` enthält keine direkten oder transitiven Light-DOM-Styles; Sass-Mixins explizit im Theme einbinden.
