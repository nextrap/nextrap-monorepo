# NTE Data Table

Spaltenbreiten: `width` als Pixelzahl, px-, %- oder fr-String. Reihenfolge: Pixel, Prozent vom Pixel-Rest, gewichtete fr-Restverteilung (Standard 1fr). Min/max gelten für Layout und Resizing. `viewState.columnWidths` überschreibt als Pixel. Geometrie liegt ausschließlich in nte-table.

Set `definition`, `data` and optionally `viewState` as properties. Leading columns can default to `pinned: true`; `viewState.pinnedColumns` overrides those defaults. Column `footer` values or callbacks create a fixed footer row. Listen for `nte-data-table-view-state-change`. Dataset editing is intentionally excluded.

`definition.defaultSortable` steuert den Standard für interaktive Sortierung; `column.sortable` hat Vorrang. Ohne Angabe gilt `true`. `defaultSortable: false` erlaubt gezieltes Opt-in per `sortable: true`. Programmatisches `viewState.sort` bleibt wirksam.
