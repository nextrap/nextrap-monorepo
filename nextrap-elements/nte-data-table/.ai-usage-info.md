# NTE Data Table

Set `definition`, `data` and optionally `viewState` as properties. Leading columns can default to `pinned: true`; `viewState.pinnedColumns` overrides those defaults. Column `footer` values or callbacks create a fixed footer row. Listen for `nte-data-table-view-state-change`. Dataset editing is intentionally excluded.

## Entry Points

- SPA: `import '@nextrap/nte-data-table'` lädt API und Default-Light-DOM-Styles automatisch.
- Theme/Seaming: `import '@nextrap/nte-data-table/unstyled'` enthält keine direkten oder transitiven Light-DOM-Styles; Sass-Mixins explizit im Theme einbinden.
