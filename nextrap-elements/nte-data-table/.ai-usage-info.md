# @nextrap/nte-data-table

Use `<nte-data-table>` to add scrolling, sticky table sections, fixed/hidden columns and leading-column pinning to one direct native Light DOM `<table>`.

```html
<nte-data-table height="32rem" pinned-columns="1" scroll-label="Orders">
  <table>
    <thead><tr><th data-width="12rem">Order</th><th data-width="8rem">Status</th></tr></thead>
    <tbody><tr><td>#1001</td><td>Open</td></tr></tbody>
    <tfoot><tr><td>Total</td><td>1</td></tr></tfoot>
  </table>
</nte-data-table>
```

The source table is also the visible and interactive table; do not clone it or forward its events. Keep rows rectangular and avoid `colspan`/`rowspan` in the MVP. Use `hidden`/`data-hidden` and `data-width` on header cells. Call `refresh()` only when automatic Mutation/Resize observation cannot see a layout input.

Package skills under `skills/` are the maintained usage and theming reference.
