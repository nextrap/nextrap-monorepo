# @nextrap/nte-data-table

Use `<nte-data-table>` around exactly one rectangular native Light DOM table. The configured `height` belongs to the scrolling `tbody`; `thead`/`tfoot` stay in normal flow outside that viewport, header widths drive every section, and `pinned-columns` pins leading visible columns. Do not clone or restructure the source table.

The component resets native table margin/padding and keeps header/footer cells on one line. Visible columns always fill at least the usable body width; when their configured widths are smaller, the last visible column receives only the derived remainder. The last body row retains its bottom separator from unused white viewport space.

The component does not install a `MutationObserver`. After changing rows, visibility, width metadata, or other layout inputs, call `refresh()`; it removes owned layout values, measures again, and freezes every visible column in pixels. Pointer resize updates only its target column. A native `caption` remains fixed above `thead`. The Shadow DOM viewport does not add a synthetic scroll track; horizontal scrolling remains native to `tbody`.

Only the `nte-data-table` host owns the outer border and radius. The viewport and all native table descendants must remain free of outer-edge borders and radii. Horizontal overflow stays on `tbody`; the footer remains at the component's bottom without a reserved synthetic scrollbar strip.

Header-cell classes `selected`, `highlight[-primary|-secondary|-success|-info|-warning|-danger]`, and `border-free` propagate to the entire column. Put indicators inside a header as `<span class="indicator">…</span>`. Use `with-header-strong` or `with-header-minimal`, plus the external `nte-data-table-header`/`nte-data-table-search` helpers for connected toolbars.

Control selection through `element.remote`: `selectRow`, `deselectRow`, `toggleRow`, `selectColumn`, `deselectColumn`, `toggleColumn`, and `clearSelection`. Targets are zero-based indices, row/header elements, or `id`/`data-row-id`/`data-column-id` strings. Selection does not require a new observer.

Cell overflow defaults to ellipsis. Override it on a table, row, or cell with `overflow-ellipsis`, `overflow-clip`, `overflow-wrap`, or `overflow-visible`.

Activate registered plugins with `features="sort reorder-columns reorder-rows"`. Built-ins sort body rows, reorder complete columns, or reorder body rows using Light-DOM controls. Custom plugins register through `nteDataTablePluginRegistry.register(name, factory)` and receive `{ host, table, remote, refresh }`; they must remove their listeners and owned controls in `disconnect()`.

The internal `ARCHITECTURE.md` is mandatory project-maintainer context and is intentionally excluded from the npm package.
