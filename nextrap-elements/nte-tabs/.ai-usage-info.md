# NTE Tabs

Import: `@nextrap/nte-tabs`. Registriert `nte-tabs` und `nte-tab`;
Typen: `NteTabs`, `NteTab`, `TabsOverflow`.

```html
<nte-tabs value="files">
  <nte-tab name="files">Dateiliste</nte-tab>
  <nte-tab name="changes" label="Change List" count="3">Änderungen</nte-tab>
  <span slot="tab-changes">✎ Änderungen</span>
</nte-tabs>
```

Direkte Tabs brauchen eindeutige Namen. Der optionale Header-Slot
`tab-<name>` ersetzt das Label; sonst gilt `label` oder `name`.
Der Dropdown verwendet die Textbeschriftung. Header dürfen keine
interaktiven Controls enthalten. Setze `tabs.value` zur Auswahl und
`tab.count` für den Counter; null entfernt ihn. Benutzerwechsel melden
`change` mit dem Namen als Detail. Inaktive Panels bleiben gemountet.
`overflow="auto"` ist Standard; Alternativen: `dropdown`, `scroll`.
`disabled` deaktiviert einen Tab. Theme bindet `default-style()` unter
`nte-tabs.style-default` oder `small-style()` unter `nte-tabs.style-sm` ein.
Parts: bar, tablist, tab, active-tab, label, count, dropdown, panel.
