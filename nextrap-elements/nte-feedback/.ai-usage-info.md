# @nextrap/nte-feedback

Use this package as the central application feedback API. Mount `<nte-feedback>` once and prefer `Feedback.*` over manual `window.dispatchEvent` calls.

Primary calls: `Feedback.loading`, `Feedback.progress`, `Feedback.success`, `Feedback.error`, `Feedback.info`, `Feedback.alert`, `Feedback.confirm`, `Feedback.open`, `Feedback.close`.

`Feedback.alert()` replaces browser `alert()`. `Feedback.confirm()` replaces browser `confirm()` and resolves to `boolean`. Use loading for pending/blocking work and progress whenever a measurable completion percentage exists. Opening helpers are awaitable and resolve when the feedback is closed.

`Feedback.loading({ variant: 'mini' })` zeigt einen nicht blockierenden
2-px-Balken in der Primärfarbe (`--nt-primary`) am oberen Viewport-Rand.
CSS animiert ihn in 200 ms auf 50 %, danach
langsamer bis 95 % und hält diesen Stand nach insgesamt 10 Sekunden.
`Feedback.ready()` beziehungsweise das
Window-Event `nextrap:ready` beendet ihn mit Abschlussanimation und Ausblenden;
anschließend wird der Loading-Promise aufgelöst. `Feedback.close()` schließt
sofort. Ohne Variante bleibt der Loading-Dialog, den Ready ebenfalls schließt;
andere Feedback-Zustände bleiben von Ready unberührt.

See `skills/nte-feedback-usage/SKILL.md` and `demo/*.demo.ts` for canonical examples.
