# @nextrap/nte-feedback

Use this package as the central application feedback API. Mount `<nte-feedback>` once and prefer `Feedback.*` over manual `window.dispatchEvent` calls.

Primary calls: `Feedback.loading`, `Feedback.progress`, `Feedback.success`, `Feedback.error`, `Feedback.info`, `Feedback.alert`, `Feedback.confirm`, `Feedback.open`, `Feedback.close`.

`Feedback.progress({ progress, ... })` displays real progress. For long-running actions without measurable progress, use `Feedback.progress({ mode: 'mock', durationMs, ... })`; it advances quickly at first, slows toward the end, closes when the duration expires, and resolves its promise. Any feedback detail may include `details` as a string or array; details render as collapsible code.

`Feedback.alert()` replaces browser `alert()`. `Feedback.confirm()` replaces browser `confirm()` and resolves to `boolean`. Opening helpers are awaitable and resolve when the feedback is closed.

See `skills/nte-feedback-usage/SKILL.md` and `demo/*.demo.ts` for canonical examples.
