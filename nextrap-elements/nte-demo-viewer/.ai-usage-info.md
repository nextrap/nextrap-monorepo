# @nextrap/nte-demo-viewer

## Entry Points

- SPA: `import '@nextrap/nte-demo-viewer'` lädt API und Default-Light-DOM-Styles automatisch.
- Theme/Seaming: `import '@nextrap/nte-demo-viewer/unstyled'` enthält keine direkten oder transitiven Light-DOM-Styles; Sass-Mixins explizit im Theme einbinden.
