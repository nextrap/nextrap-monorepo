# Programmatic Content
{: layout="1;.container.nte-offcanvas-demo"}

Die Komponente kann auch programmatisch erzeugt werden. `content` akzeptiert ein Lit-Template oder ein bestehendes `HTMLElement`/Custom Element.

<button class="btn btn-primary" id="demo-programmatic-template">Template öffnen</button>
<button class="btn btn-secondary" id="demo-programmatic-element">HTMLElement öffnen</button>

Der Constructor-Content befüllt den Main-Bereich und kann später über die `content` Property ersetzt werden.
