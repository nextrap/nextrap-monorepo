# @nextrap/nte-offcanvas

Offcanvas element for slide-in panels.

## Import

```ts
import '@nextrap/nte-offcanvas';
import type { NteOffcanvas } from '@nextrap/nte-offcanvas';
```

## Usage

```html
<button onclick="document.querySelector('#menu').open()">Open</button>

<nte-offcanvas id="menu">
  <div slot="header">
    <strong>Menu</strong>
    <button data-nt-dismiss="offcanvas">Close</button>
  </div>

  <p>Content</p>

  <button slot="footer" data-nt-dismiss="offcanvas">Close</button>
</nte-offcanvas>
```

`open()`, `close()` and `toggle()` control the `opened` property. `backdrop` defaults to `true`. Use `open-group` for explicit mutual exclusion across placements and interaction modes. Two modal surfaces at the same effective placement are also sequenced automatically; the second waits for the first to close. Non-modal surfaces at the same placement remain independent. Use `layout-group` to associate push surfaces with panes. A pane accepts whitespace-separated group names and ignores push events when no group is configured. `data-group-name` is the deprecated alias for `open-group`.

## Styling

```scss
@use '@nextrap/nte-offcanvas' as offcanvas;

nte-offcanvas.style-default {
  @include offcanvas.default-style();
}
```

`SetDefaultStyleMixin` adds `style-default` automatically when no `style-*` class is present. The element provides `header`, default, `footer`, and `close` slots. Its built-in control uses the shared `@nextrap/style-elements` `close-btn()` mixin and `--nt-icon-close`. Theme through `offcanvas`, `dialog`, `header`, `main`, `footer`, `close`, and `close-button` parts; the pane exposes `pane`. Keep visual defaults in `default-style()`, not in Shadow DOM CSS.

`default-style()` bezieht den normalen Hintergrund aus `--nt-surface` in Style Base; `light-dark()` berücksichtigt das geerbte `color-scheme` einschließlich Gerätepräferenz und expliziter Auswahl über `data-nt-scheme`. Style Base wird einmal vom Theme eingebunden. Hintergrund, Backdrop und Schatten werden direkt über `--nte-offcanvas-background`, `--nte-offcanvas-backdrop` und `--nte-offcanvas-shadow` konfiguriert, ohne weitere Farb-Aliase im Shadow DOM. Ohne Style-Variante oder expliziten Hintergrund-Override verwendet die Fläche das geerbte `--nt-surface` als Fallback, einschließlich der seitlichen Flächenverlängerung während der Animation. Backdrop und Schatten bleiben ohne Style-Variante transparent beziehungsweise ausgeschaltet. Die Sass-Parameter bleiben erhalten; die Migration der entfernten generischen CSS-Variablen steht in der README.
