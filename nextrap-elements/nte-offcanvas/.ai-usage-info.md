# @nextrap/nte-offcanvas

Offcanvas element for slide-in panels.

## Import

```ts
import '@nextrap/nte-offcanvas';
import type { NteOffcanvas } from '@nextrap/nte-offcanvas';
```

## Usage

```html
<button onclick="document.querySelector('#menu').open()">Open</button>

<nte-offcanvas id="menu">
  <div slot="header">
    <strong>Menu</strong>
    <button data-nt-dismiss="offcanvas">Close</button>
  </div>

  <p>Content</p>

  <button slot="footer" data-nt-dismiss="offcanvas">Close</button>
</nte-offcanvas>
```

`open()`, `close()` and `toggle()` control the `opened` property. `backdrop` defaults to `true`. `data-group-name` dispatches Nextrap group open/close events for paired controls.

## Styling

```scss
@use '@nextrap/nte-offcanvas' as offcanvas;

nte-offcanvas.style-default {
  @include offcanvas.default-style();
}
```

`SetDefaultStyleMixin` adds `style-default` automatically when no `style-*` class is present. Use `::part(backdrop)`, `::part(offcanvas)`, `::part(header)`, `::part(main)` and `::part(footer)` for theme styling. Keep visual defaults in `default-style()`, not in Shadow DOM CSS.
