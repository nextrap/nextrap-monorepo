# ScrollSpy

Scroll the content area. The navigation is generated from the `data-title` attributes and follows the active section.

  <aside class="nte-scrollspy-demo__navigation" aria-label="On this page">

  <article id="scrollspy-demo-content" class="nte-scrollspy-demo__content" tabindex="0">
    <section id="scrollspy-introduction" data-title="Introduction">
      <h2>Introduction</h2>
      <p>ScrollSpy connects a compact navigation with sections in a page or in a scrollable content container.</p>
      <p>The active navigation item changes as the corresponding section moves through the visible area.</p>
    </section>
    <section id="scrollspy-automatic-navigation" data-title="Automatic navigation">
      <h2>Automatic navigation</h2>
      <p>When no explicit data is configured, every descendant with a <code>data-title</code> attribute becomes a navigation item.</p>
      <p>Existing section IDs are used as link targets; missing IDs are generated by the component.</p>
    </section>
    <section id="scrollspy-progress" data-title="Progress tracking">
      <h2>Progress tracking</h2>
      <p>Progress tracking marks sections before the active section as visited, which gives readers a quick sense of position.</p>
      <p>The navigation links use native fragment URLs and smooth scrolling.</p>
    </section>
    <section id="scrollspy-theming" data-title="Theming">
      <h2>Theming</h2>
      <p>The component consumes the current <code>--nt-*</code> token contract and provides safe fallbacks when no Nextrap theme is loaded.</p>
      <p>Shadow parts and component custom properties remain available for application-specific themes.</p>
    </section>
  </article>
</div>
