# nte-icon

Import `@nextrap/nte-icon`. Einzige Property: `src`; sonst Klassen wie
`bi bi-house`. Standard `1em × 1em`, Größe per CSS/`--nte-icon-size` oder
Light-DOM-Klassen `size-xs` bis `size-xxl` aus `sizes()`. Farbe wird geerbt.
Native ARIA-Attribute übernehmen die Beschriftung. Die einmal registrierte
Schrift lädt durch die normale CSS-Font-Nutzung; keine zusätzliche State-API.
Konfiguration vor der ersten Instanz: `NTE_ICON_CONFIG.bootstrapIconsFontUrl`.
