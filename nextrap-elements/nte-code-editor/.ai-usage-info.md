# NTE Code Editor

CodeMirror-6-Wrapper `nte-code-editor` mit synchroner `value`-Property,
`input`/`change`, nativer Formularanbindung und `defaultValue`/Reset.
Sprachen: HTML, Markdown mit HTML und Sprach-Fences, CSS, JavaScript,
TypeScript, SCSS; `text` deaktiviert sprachspezifische Funktionen.

`originalValue` aktiviert den Vergleich: `diffMode = 'unified'` ist der
Default, `side-by-side` zeigt beide Dokumente mit gemeinsamer vertikaler
Scrollfläche. `diffOrientation` tauscht die Seiten; `revertControls` wählt
die Kopierrichtung oder `none`. Original → Arbeitsfassung erzeugt `input`
und `change`, die Gegenrichtung `original-change` mit `detail.value`.
`value` bleibt immer die Arbeitsfassung und der Formularwert.

`folding`, `htmlElements` und `classNames` gelten auch im Split. `extensions`
und `editorView` betreffen die Arbeitsfassung; `mergeView` öffnet im Split
beide Views. Höhe am gemeinsamen Part `editor` begrenzen. Quellcode immer
per `value` übergeben; der Default-Slot ist ein sichtbarer Diagnose-Fallback.
Optionale KI-Callbacks `inlineCompletion` und `inlineEdit` liefern async
`{ text }` oder `null`. Manuell per `triggerInlineCompletion()`/`Mod-Shift-Space`
und `triggerInlineEdit()`/`Mod-k`; Tab übernimmt, Escape verwirft. Der Edit-Diff
ändert `value` erst nach Accept. Ohne Callback ist die jeweilige Funktion aus.
Exportierte Request-/Response-Typen, `AbortSignal`, Konfiguration und Beispiele:
README Abschnitt 8 und `07-ai.demo.ts`.
