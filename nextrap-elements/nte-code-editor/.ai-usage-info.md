# NTE Code Editor

CodeMirror-6-Wrapper `nte-code-editor` mit synchroner `value`-Property,
`input`/`change`, nativer Formularanbindung und `defaultValue`/Reset.
Sprachen: HTML, Markdown mit HTML und Sprach-Fences, CSS, JavaScript,
TypeScript, SCSS, YAML und PHP; `text` deaktiviert sprachspezifische Funktionen.
Markdown unterstützt YAML-Frontmatter. `jekyll`/`liquid` kombinieren
YAML-Frontmatter mit Liquid-Templates und HTML.
CSS/SCSS bieten in editierbaren Ansichten einen Inline-Color-Picker.
Mittlere Maustaste oder Alt + linke Maustaste ziehen eine Spaltenauswahl.

`oldValue: string | null` ist die Vergleichsbasis (Alias für `originalValue`).
`null` beziehungsweise `originalValue = undefined` beendet den Vergleich;
`''` ist eine gültige Baseline. Der 24px-Header erscheint automatisch mit
Vergleichsbasis und bietet Split, Unified Diff (unveränderte Zeilen eingeklappt)
und einen Umschalter zwischen schreibgeschütztem Original und aktueller Version.
Mit `header = true` bleibt der Header auch ohne Vergleich sichtbar; der
optionale Slot `header` steht links zur Verfügung. Theme-Parts: `header`,
`header-content`, `header-button`, `active-header-button`, `original-preview`.
`diffMode = 'unified'` ist der Default, `side-by-side` zeigt beide Dokumente
mit gemeinsamer vertikaler Scrollfläche. `diffOrientation` tauscht die Seiten; `revertControls` wählt
die Kopierrichtung oder `none`. Original → Arbeitsfassung erzeugt `input`
und `change`, die Gegenrichtung `original-change` mit `detail.value`.
`value` bleibt immer die Arbeitsfassung und der Formularwert.

`folding`, `htmlElements` und `classNames` gelten auch im Split. `extensions`
und `editorView` betreffen die Arbeitsfassung; `mergeView` öffnet im Split
beide Views. Höhe am gemeinsamen Part `editor` begrenzen. Quellcode immer
per `value` übergeben; der Default-Slot ist ein sichtbarer Diagnose-Fallback.
Optionale KI-Callbacks `inlineCompletion` und `inlineEdit` liefern async
`{ text }` oder `null`. Marimo rendert Ghost-Text (Tab/Escape).
Edit/Insert (`Mod-k`/`triggerInlineEdit()`) öffnet ein Prompt-Feld und eine
separate Merge-Vorschau. Mit Markierung werden ganze Zeilen ersetzt, ohne
Markierung wird am Cursor eingefügt (`selection: ''`, `from === to`).
Nur Accept ändert `value`; Reject/Escape verwirft den Vorschlag.
Ohne Callback ist die jeweilige Funktion aus. Completion erhält
`language`, `codeBefore`, `codeAfter`, `cursor`, `signal`; Edit erhält
zusätzlich `selection`, `from`, `to`, `prompt` statt `cursor` (optionales
`signal`). Positionen sind nullbasierte UTF-16-Offsets; `to` ist exklusiv.
Completion liefert die Ergänzung, Edit den Ersatz oder einzufügenden Text.
`editor.editorView` ist nach `updateComplete` verfügbar; deren `dispatch()`
wendet CodeMirror-Transaktionen an. Für normale Textzugriffe genügt `value`.
Typen mit Beispielwerten: README Abschnitt 8 und `07-ai.demo.ts`.
