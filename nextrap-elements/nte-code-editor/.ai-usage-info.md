# NTE Code Editor

CodeMirror-6-Wrapper `nte-code-editor` mit synchroner `value`-Property,
`input`/`change`, nativer Formularanbindung und `defaultValue`/Reset.
Sprachen: HTML, Markdown mit HTML und Sprach-Fences, CSS, JavaScript,
TypeScript, SCSS; `text` deaktiviert sprachspezifische Funktionen.

`folding` ist standardmäßig aktiv. `htmlElements` und `classNames` ergänzen
Completion; `originalValue` aktiviert den Unified-Diff. `extensions` und
`editorView` öffnen die CodeMirror-API. Quellcode immer per `value` übergeben;
der Default-Slot ist ausschließlich ein sichtbarer Diagnose-Fallback.
