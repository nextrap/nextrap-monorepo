# @nextrap/nte-infiniscroll

Vanilla custom element for horizontally repeating / auto-scrolling content.

## Import

```ts
import '@nextrap/nte-infiniscroll';
```

## Usage

```html
<nte-infiniscroll auto-scroll stop-on-hover scroll-speed="1">
  <img src="/logo-1.svg" alt="" />
  <img src="/logo-2.svg" alt="" />
</nte-infiniscroll>
```

On connect, direct children are cloned into the internal `scrollslot`. Attributes include `auto-scroll`, `snap`, `stop-on-hover`, `ease-stop-on-drag`, `slow-down-on-stop`, `acceleration-factor`, and `scroll-speed`.

Keep styles minimal; host CSS variables currently include `--height` and `--space`.
