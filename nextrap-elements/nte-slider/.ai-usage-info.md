# @nextrap/nte-slider

Element package containing `nte-slider` and its internal `nte-slide` sub-layout.

## Import

```ts
import '@nextrap/nte-slider';
```

## Usage

```html
<nte-slider autoplay autoplay-interval="5000">
  <section>
    <img src="/slide.jpg" alt="" />
    <h2>Slide title</h2>
  </section>
</nte-slider>
```

Direct `section:not(.keep)` children are converted to `nte-slide` via `data-set-attribute-layout`. `nte-slide` assigns direct images or `p:has(img:not(.keep))` to the `image` slot.

## Parts

Use `::part(wrapper)`, `::part(content)`, `::part(navigation)`, `::part(nav-prev)`, `::part(nav-next)`, `::part(indicator)`, and `::part(indicator-dot)` for theme styling. Slide parts include `wrapper`, `image`, `gradient`, and `content`.

## Entry Points

- SPA: `import '@nextrap/nte-slider'` lädt API und Default-Light-DOM-Styles automatisch.
- Theme/Seaming: `import '@nextrap/nte-slider/unstyled'` enthält keine direkten oder transitiven Light-DOM-Styles; Sass-Mixins explizit im Theme einbinden.
