# @nextrap/nte-scroll-to-top

`<nte-scroll-to-top>` renders an accessible fixed button after the page passes `threshold` (default: `300`). Configure
scrolling with `scroll-behavior="smooth|auto"`, localize it with `aria-label`, and replace the arrow through
`slot="icon"`. Theme `nte-scroll-to-top.style-default` with the package `default-style()` SCSS mixin and the public
`button` and `icon` parts.

## Entry Points

- SPA: `import '@nextrap/nte-scroll-to-top'` lädt API und Default-Light-DOM-Styles automatisch.
- Theme/Seaming: `import '@nextrap/nte-scroll-to-top/unstyled'` enthält keine direkten oder transitiven Light-DOM-Styles; Sass-Mixins explizit im Theme einbinden.
