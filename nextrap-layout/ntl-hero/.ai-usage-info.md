# @nextrap/ntl-hero

Hero-Layout für Content-Pane-Abschnitte mit einer Hintergrundebene.

- Registrierung: `import '@nextrap/ntl-hero'`; Hero-Light-DOM-Styles werden dabei nicht geladen.
- Sass-API: `@use '@nextrap/ntl-hero' as hero;` erzeugt kein CSS. Das Theme bindet `hero.default-style()` an `ntl-hero.style-default`.
- `nt-core` ergänzt `style-default` automatisch, wenn keine `style-*` Klasse vorhanden ist. Eigene Varianten binden ihre vollständige Baseline selbst ein.
- Slots: `bg`, `top-title`, `title`, unbenannter Hauptinhalt und `footer`.
- Parts: `root`, `background`, `wrapper`, `top-title`, `title`, `content`, `footer`.
- Instanzvariablen: `--bg-color`, `--container-width`, `--min-height`, `--max-height`, `--top-offset`, `--breakpoint`.
- `--height-offset` wird von der Komponente aus `offsetTop` gesetzt. Das Theme stellt `tj-responsive` bereit.
- Die Baseline bewahrt Viewport-Höhe, Zentrierung und Bildanpassung; funktionaler Hintergrundzuschnitt und leere Slots bleiben im Shadow DOM.

```markdown
---
{: layout="1;ntl-hero" section-style="--min-height: 480px;"}

# Willkommen
{: section-slot="title"}

Ein kurzer Einstieg.
```

Parameter, Migration und Theme-Beispiele: [README.md](README.md).

## Entry Points

- SPA: `import '@nextrap/ntl-hero'` lädt API und Default-Light-DOM-Styles automatisch.
- Theme/Seaming: `import '@nextrap/ntl-hero/unstyled'` enthält keine direkten oder transitiven Light-DOM-Styles; Sass-Mixins explizit im Theme einbinden.
