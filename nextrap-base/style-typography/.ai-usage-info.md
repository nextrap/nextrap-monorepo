# @nextrap/style-typography

## Purpose

Provides typography/prose styling primitives for rich text contexts.

## Usage contract

- Follow `docs/style-packages-architecture.md`.
- `index.scss` is the Sass API entry; `default.scss` is the explicit default CSS output entry (for new/updated style packages).
- Public classes should map to same-named mixins where meaningful.
- Mixins must remain composable on arbitrary selectors/scopes (for theme-layer semantic mapping).
- Prefer consuming `--nt-*` tokens from `@nextrap/style-base` instead of private cross-package Sass internals.
