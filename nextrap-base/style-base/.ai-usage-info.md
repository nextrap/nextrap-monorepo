# @nextrap/style-base

## Purpose

Provides the global Nextrap design tokens, Theme API v1, and container-related CSS variables.

Use this package to bootstrap theme variables such as colors, typography, spacing, border radii, and container widths for the main document.

This package is a **global theme/token layer**. It is not a component stylesheet.

## Important rule

- Include `@nextrap/style-base` / `@nextrap/style-base/module` only in the **main document / theme stylesheet**.
- Do **not** include it inside the **shadow DOM** styles of components.
- Add it once at theme level, then consume the generated CSS variables in components and theme partials.

## Theme API v1 (preferred)

### Minimal single-mode theme

```scss
@use '@nextrap/style-base/module' as nt;

:root {
  @include nt.theme((
    primary: #0057b8,
    neutral: #667085,
    font-family: ('Inter', sans-serif),
    radius: .5rem
  ));
}
```

### Single dark-mode theme

```scss
:root {
  @include nt.theme((
    mode: dark,
    primary: #66aaff,
    neutral: #98a2b3
  ));
}
```

### Multi-scheme (light + dark auto-derived)

```scss
:root {
  @include nt.theme((
    primary: #0057b8,
    neutral: #667085,
    schemes: (
      light: auto,
      dark: auto
    )
  ));
}
```

The `schemes` key generates:
- Light tokens directly on `:root` and via `[data-nt-scheme='light']`
- Dark tokens via `[data-nt-scheme='dark']`

For system `prefers-color-scheme` support, add `scheme-switcher` separately:

```scss
@include nt.scheme-switcher((
  primary: #0057b8,
  neutral: #667085,
  schemes: (
    light: auto,
    dark: auto
  )
), system);
```

### Partial dark overrides

```scss
:root {
  @include nt.theme((
    primary: #0057b8,
    neutral: #667085,
    schemes: (
      light: auto,
      dark: (
        primary: #5fa8ff,
        surface: #101214
      )
    )
  ));
}
```

## Theme API v1 Inputs (integrator-facing)

| Input | Description |
|---|---|
| `primary` | Brand color |
| `neutral` | Neutral/gray color (used for surfaces, text, borders) |
| `font-family` | Font family (shorthand for `font-family-base`) |
| `radius` | Border radius (shorthand; derives -sm and -lg automatically) |
| `mode` | `light` or `dark` (default: `light`) |
| `density` | `comfortable` (default) or `compact` |
| `schemes` | Map of schemes: `(light: auto, dark: auto)` |

## Legacy / Backward-Compatible API (still works)

```scss
@use '@nextrap/style-base/module' as nt;

:root {
  @include nt.nextrap-theme((
    primary: #2b94d6,
    accent: #2b94d6,
    secondary: #4c4c4c,
    font-family-base: sans-serif,
    rcs: true
  ));
}
```

## Public Semantic CSS Variables

### Brand / State colors

```
--nt-primary              Brand color
--nt-secondary            Secondary color
--nt-accent               Accent color
--nt-success              Success state
--nt-warning              Warning state
--nt-danger               Danger/error state
--nt-info                 Info state
```

### Interaction state tokens (auto-generated per color)

```
--nt-primary-hover        Hover state color for primary
--nt-primary-active       Active state color for primary
--nt-text-on-primary      Readable text on primary background

(Same pattern for: secondary, accent, success, warning, danger, info)
```

### Surfaces / Content

```
--nt-surface              Default page/background surface (replaces --nt-body)
--nt-surface-muted        Secondary surface (replaces --nt-body-secondary)
--nt-surface-raised       Elevated surface (replaces --nt-body-tertiary)
--nt-text                 Default text color
--nt-text-muted           Subdued text color
--nt-border               Default border color
--nt-focus                Focus indicator color
--nt-link                 Link color
--nt-link-hover           Link hover color
--nt-link-active          Link active color
```

### Typography

```
--nt-font-family          Base font family (shorthand)
--nt-font-size            Base font size (shorthand)
--nt-line-height          Base line height (shorthand)
```

### Shape

```
--nt-radius               Border radius (shorthand)
```

### Semantic spacing

```
--nt-spacing-text         Text rhythm (paragraph/list spacing)
--nt-spacing-control      Small control spacing (buttons/inputs)
--nt-spacing-component    Default component inner spacing
--nt-spacing-layout       Layout gaps between components
--nt-spacing-section      Section-to-section spacing (fluid)
```

### Container

```
--nt-container-max        Maximum container width (default: 1320px)
--nt-container-gutter     Container side padding
```

### Container usage pattern

```css
.container {
  width: min(
    calc(100% - 2 * var(--nt-container-gutter)),
    var(--nt-container-max)
  );
  margin-inline: auto;
}
```

```
--nt-background          → --nt-surface
--nt-font-family-base    → --nt-font-family

```

## Advanced / Internal Tokens (not primary theme API)

These are generated automatically. Nextrap packages may use them; integrators normally don't need to configure them:

```
--nt-space-0 ... --nt-space-10    Primitive spacing scale
--nt-gray-100 ... --nt-gray-900   Gray scale derived from neutral
--nt-fs-1 ... --nt-fs-6           Text scale
--nt-fs-h1 ... --nt-fs-h6         Header scale
--nt-*-subtle                      Subtle color variants
--nt-*-emphasis                    Emphasis color variants
--nt-font-family-base              Legacy font token
--nt-font-size-base                Legacy font size token
--nt-line-height-base              Legacy line-height token
--nt-container-width               Legacy responsive container width
```

## Component token pattern (how components consume this)

```css
.btn {
  --btn-bg: var(--nt-primary);
  --btn-bg-hover: var(--nt-primary-hover);
  --btn-bg-active: var(--nt-primary-active);
  --btn-text: var(--nt-text-on-primary);

  background: var(--btn-bg);
  color: var(--btn-text);

  &:hover { background: var(--btn-bg-hover); }
  &:active { background: var(--btn-bg-active); }
}
```

## Architecture contract (must keep)

- `@nextrap/style-base` is token-only.
- `@nextrap/style-base/default` must also stay visually side-effect free.
- Only emit Nextrap CSS custom properties (`--nt-*`) and related token aliases in intended theme scopes.
- Do not emit reset, typography defaults, native-element styling, utility classes, or component styling here.
- Keep cross-package interoperability token-based (`var(--nt-*)`), not by private Sass internals.
