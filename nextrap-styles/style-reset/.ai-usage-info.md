# @nextrap/style-reset

Stellt das Sass-Mixin `reset()` für Dokument- und Shadow-DOM-Styles bereit.

## Demo

Die Paket-Demos laufen über `@trunkjs/vite-demo-viewer` auf `/` und liegen unter `demo/**/*.demo.ts`.
Sie sind auch im zentralen Viewer über `npm run demo` verfügbar; alte HTML-Einstiege und Demo-Loader entfallen.

## Entry Points

- SPA: `import '@nextrap/style-reset'` lädt API und Default-Light-DOM-Styles automatisch.
- Theme/Seaming: `import '@nextrap/style-reset/unstyled'` enthält keine direkten oder transitiven Light-DOM-Styles; Sass-Mixins explizit im Theme einbinden.
