# @nextrap/style-elements AI Usage Info

Reusable visual element style patterns as composable Sass mixins.

This package owns `.prose` and its rich-content sub-patterns. `style-typography` only supplies the underlying native text-element typography and may be loaded alongside it when a complete rich-content presentation is wanted.

## Architecture

- `index.scss` = mixin API only (no CSS output on `@use`)
- `_style-elements.scss` contains the matching `style-elements()` aggregate mixin for unambiguous source-map references
- `default.scss` = only materializes `style-elements()` at root

## Available mixins

**Prose:** `prose()`, `prose-xl()`
**Table:** `table()`, `table-striped()`, `table-bordered()`, `table-hover()`, `table-sm()`
**Lists:** `list()`, `list-unstyled()`, `list-inline()`, `list-inline-item()`, `list-diamond()`, `list-status-plain()`, `list-status-circle()`, `list-item-tick()`, `list-item-cross()`
**List group:** `list-group()`, `list-group-flush()`
**Container:** `container()`, `container-fluid()`

## Usage examples

### Apply default CSS classes
```scss
@use '@nextrap/style-base/default';
@use '@nextrap/style-typography/default';
@use '@nextrap/style-elements/default';
// Now .prose, .table, .list, .list-status-circle, .list-group, .container etc. are available
```

### Compose mixins in a theme scope
```scss
@use '@nextrap/style-elements' as e;

.my-theme {
  article {
    @include e.prose();
  }

  table {
    @include e.table();
    @include e.table-striped();
  }

  nav > ul {
    @include e.list-group();
    @include e.list-group-flush();
  }
}
```

### Status lists
```html
<ul class="list list-status-circle">
  <li>Neutral by default</li>
  <li class="list-item-tick">Available</li>
  <li class="list-item-cross">Unavailable</li>
</ul>
```

Use `.list-status-plain` for standalone symbols or `.list-status-circle` for symbols inside colored circles. Direct `li` children are neutral by default. Override the inherited `1em` indicator size with `--list-status-indicator-size` on the list when needed.

### Modifier mixins are independent (do not include base)
```scss
// Add striped to a table that already has .table applied:
.my-table {
  @include e.table();
  @include e.table-striped();
  @include e.table-bordered();
}
```

## Notes

- Uses `--nt-*` CSS custom properties for theming — no private style-base imports.
- `prose()` includes box, table, heading, and image sub-patterns with local CSS variables.
- `list-diamond()` intentionally uses a geometric rotated square, not a font glyph. Its size and offset are tied to `1lh` so the marker stays vertically centered on the first text line; preserve that contract when editing it.
- `style-typography` does not forward or materialize `.prose`; consumers opt into this package explicitly.
- Prose consumes the real base tokens `--nt-text`, `--nt-text-muted`, `--nt-header`, `--nt-link` and `--nt-link-hover`; semantic surfaces override these tokens locally.
